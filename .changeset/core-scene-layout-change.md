Keep an Instrument object's parts through the frame a layout change reaches core before its producer (#156). A media preference that changes a border (`prefers-contrast`, `forced-colors`, `prefers-color-scheme`) changes the layer's box in one frame; core's `ResizeObserver` draws it first, so the scene built for the old box was checked against the new one and an edge object was drawn at Relief for two composited frames, GPU on. The check still runs against the layer's current box and placement; an object the same scene already passed at the box it was built for, and that now fails only the bounds check, keeps that verdict until the next scene, which is checked against the new box. Where the layer sits on the stage does not matter; a different scene `extent` or geometry, a changed structure or an object already stepped down does. A box that grows holds nothing. While a verdict is held the layer has a `layout:` warning and `state().instrument.layers[].layoutHeld` (`{ objects, frames }`); the composite is the new box plus 1 px, so held parts are cropped at it. A new scene whose bounds leave the box still steps down with `containment`.
